## 🎯 Purpose
Share BI/Analytics dashboards and materials that serve as practical references for:
- Effective data visualization and storytelling.
- Good practices in modeling, DAX, and design.
- Training and reproducibility for the community.

---

## 🚀 How to open reports
1. **Download** the `.pbix` you’re interested in.  
2. **Open** it with **Power BI Desktop** (recent version recommended).  
3. If prompted about external visuals or permissions:
   - Accept/install the requested visuals (e.g., ZoomCharts, Deneb).
   - Update Power BI Desktop if needed.

> **Note:** Some reports may include `.pbit` (template). When opening, **select your data source** or load a sample dataset if prompted.

## 🧩 Visuals & dependencies
- Some dashboards use **third-party visuals** (e.g., *ZoomCharts Drill Down Visuals*).  
- Without a license, you may see a **watermark** or limited editing features; **view** mode typically works fine.

---

## 🔐 Data & privacy
- Included data is **public, synthetic, or anonymized** when applicable.  
- No credentials or sensitive information are shared.  
- If a report connects to external services, secrets are **not** included in this repo.

---

## ❓ Quick FAQ
- **“The .pbix won’t open”** → Update Power BI Desktop to the latest version.  
- **“It asks for an external visual”** → Accept/install the requested visual on open.  
- **“Data is missing”** → Check if the report relies on local files or non-public services.

## 🚀 Cómo abrir los reportes
1. **Descarga** el `.pbix` de tu interés.  
2. **Ábrelo** con **Power BI Desktop** (se recomienda versión reciente).  
3. Si aparecen avisos de visuales externos o permisos:

> **Nota:** algunos reportes pueden incluir `.pbit` (plantilla). Al abrir, **elige tu origen de datos** o carga un dataset de ejemplo si se solicita.
